# Contributing

Thanks for contributing.

## Development

1. Fork the repository.
2. Create a focused branch.
3. Make one logically scoped change.
4. Add or update tests.
5. Run the test suite.
6. Update documentation when behavior changes.
7. Open a pull request describing the change and test results.

## Scope

Keep the project focused on deterministic auditing of FAQ content and FAQPage structured data. Avoid claims about rankings, indexing guarantees, or guaranteed Google search appearances.
